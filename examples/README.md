# Examples

Short, illustrative transcripts showing a skill's trigger firing and the shape
of its output. These are representative examples written to match each
skill's actual SKILL.md instructions — not logs of a real user session — so
you can see what "good" looks like before you try a skill on your own repo.

- [git-rescue.md](git-rescue.md)
- [migration-guard.md](migration-guard.md)
- [env-detective.md](env-detective.md)
- [atomic-io.md](atomic-io.md)

Want to add one for another skill? Keep it short (a realistic trigger message,
then the key beats of the response — not a full essay) and make sure it
matches what the skill's SKILL.md actually says to do.
